1. Launch app
   → Should open to "Offline Assessment" home screen
   → No sign-in required ✓

2. Create Subject
   → Tap "NEW SUBJECT FOLDER"
   → Enter "Mathematics"
   → Folder appears ✓

3. Download Template
   → Tap menu (⋮) top-right
   → Select "Download Templates"
   → Choose "50 Items"
   → PDF downloads and opens ✓

4. Print Template
   → Print the downloaded PDF
   → Use for testing scanning

5. Create Exam
   → Tap on "Mathematics" folder
   → Tap "NEW EXAM"
   → Name: "Midterm Exam", Questions: 50
   → Set answer key (A, B, C, D for each question)
   → Save ✓

6. Scan Sheets
   → Open "Midterm Exam"
   → Tap "SCAN SHEETS"
   → Take photo of filled answer sheet
   → Student result appears ✓

7. Export Results
   → Tap "EXPORT TO CSV"
   → Share via any app
   → Open in Excel/Sheets ✓
