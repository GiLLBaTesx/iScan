# Premium Exam Scanner - Android

A premium exam scanning and grading application for Android with Apple-inspired glassmorphism design using a white and blue color scheme.

## Features

### 🎨 Design Features
- **Glassmorphism UI**: Premium frosted glass effect with soft shadows
- **Apple-inspired Design**: Clean, minimalist interface following iOS design principles
- **White & Blue Color Scheme**: Professional color palette with primary blue (#007AFF) and clean whites
- **Premium Typography**: SF Pro-inspired font system with proper spacing and weights
- **Smooth Animations**: Fluid transitions and interactions

### 📱 Functional Features
- **Exam Management**: Create, view, and manage multiple exams
- **Sheet Scanning**: Capture and grade exam sheets using camera
- **Score Tracking**: View individual student scores and class statistics
- **Item Analysis**: Analyze question performance with visual charts
- **Answer Key Editor**: Set correct answers with alternative options support
- **Export Capabilities**: Export exam results and statistics

## Design System

### Colors
- **Primary Blue**: `#007AFF` - Main interactive elements
- **Light Blue**: `#5AC8FA` - Secondary accents
- **Background White**: `#FAFAFC` - App background
- **Surface White**: `#FFFFFF` - Card backgrounds
- **Glass Overlay**: 80% white with blur effect

### Components
- **GlassCard**: Reusable glassmorphic card component
- **FloatingGlassCard**: Elevated glass card with shadow
- **GlassButton**: Interactive button with glass effect

### Typography
Based on SF Pro Display scale:
- Display: 34/28/22sp (Large/Medium/Small)
- Headline: 20/17/15sp (Large/Medium/Small)
- Body: 17/15/13sp (Large/Medium/Small)
- Label: 15/13/11sp (Large/Medium/Small)

## Technical Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Material Design**: Material3
- **Navigation**: Compose Navigation
- **Camera**: CameraX
- **ML/AI**: ML Kit for text recognition
- **Charts**: MPAndroidChart

## Setup Instructions

1. **Prerequisites**
   - Android Studio Hedgehog or later
   - Kotlin 1.9.0+
   - Android SDK 26+ (Target SDK 34)

2. **Build Configuration**
   ```bash
   ./gradlew build
   ```

3. **Run Application**
   - Open project in Android Studio
   - Sync Gradle files
   - Run on emulator or physical device (Android 8.0+)
