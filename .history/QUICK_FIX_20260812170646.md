# Quick Fix Guide

## If the app won't build in Android Studio:

### Option 1: Let Android Studio Fix It (EASIEST)
1. **Open the project** in Android Studio
2. When prompted **"Gradle files have changed"** → Click **"Sync Now"**
3. If asked to **"Update Gradle"** → Click **"Update"**
4. Wait for sync to complete (2-5 minutes)
5. Click **Run** ▶️

### Option 2: Manual Gradle Wrapper Fix
If Android Studio shows Gradle errors:

1. **Delete gradle cache:**
   ```bash
   cd /Users/jcolasi/Desktop/test-scanner
   rm -rf .gradle gradle/wrapper/gradle-wrapper.jar
   ```

2. **Open in Android Studio** → It will auto-download Gradle wrapper

3. **Sync Project** (elephant icon in toolbar)

### Option 3: Fresh Android Studio Setup
1. **File → Invalidate Caches / Restart**
2. Choose **"Invalidate and Restart"**
3. Wait for indexing to complete
4. **File → Sync Project with Gradle Files**

### Common Issues:

**"Could not find gradle-wrapper.jar"**
- Solution: Open in Android Studio, it will auto-download

**"SDK not found"**
- Solution: Update `local.properties` with your SDK path:
  ```
  sdk.dir=/Users/YOUR_USERNAME/Library/Android/sdk
  ```

**"Kotlin version mismatch"**
- Solution: Let Android Studio update Kotlin plugin when prompted

**Build errors after sync**
- Solution: **Build → Clean Project** then **Build → Rebuild Project**

### If Nothing Works:
Create a new Android Studio project and copy these folders:
- `app/src/main/java/` → All Kotlin files
- `app/src/main/res/` → All resources
- `app/build.gradle` → Build configuration
- `build.gradle` → Project configuration

Then sync and run!

## The app WILL work once Android Studio syncs properly!
