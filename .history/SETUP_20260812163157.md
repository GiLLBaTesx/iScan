# Android Studio Setup Guide

## Quick Start

### 1. Open Project in Android Studio
1. Launch **Android Studio**
2. Select **File > Open**
3. Navigate to `/Users/jcolasi/Desktop/test-scanner`
4. Click **Open**

### 2. Wait for Gradle Sync
Android Studio will automatically:
- Download Gradle wrapper (if needed)
- Download all dependencies
- Index the project files
- Build the project configuration

This may take 2-5 minutes on first load.

### 3. Update SDK Path (If Needed)
If you see SDK errors, update `local.properties`:
```properties
sdk.dir=/Users/YOUR_USERNAME/Library/Android/sdk
```

Replace `YOUR_USERNAME` with your actual macOS username.

### 4. Sync Gradle Files
- Click the **Sync Project with Gradle Files** button (elephant icon) in the toolbar
- Or go to **File > Sync Project with Gradle Files**

### 5. Run the App
1. Connect an Android device (Android 8.0+) or start an emulator
2. Click the **Run** button (green play icon)
3. Select your device from the dropdown
4. Wait for the app to install and launch

## Troubleshooting

### "SDK not found" Error
1. Go to **Android Studio > Preferences > Appearance & Behavior > System Settings > Android SDK**
2. Note the SDK location path
3. Update `local.properties` with that path

### Gradle Sync Failed
1. Click **File > Invalidate Caches / Restart**
2. Choose **Invalidate and Restart**
3. Wait for Android Studio to restart and re-index

### Dependencies Not Downloading
1. Check your internet connection
2. Go to **File > Settings > Build > Gradle**
3. Ensure **Offline mode** is unchecked

### Build Errors
1. Clean the project: **Build > Clean Project**
2. Rebuild: **Build > Rebuild Project**
3. Check you have Java 8+ installed

## System Requirements

- **Android Studio**: Hedgehog (2023.1.1) or later
- **Gradle**: 8.2 (auto-downloaded)
- **Kotlin**: 1.9.0
- **Java JDK**: 8 or higher
- **Android SDK**: API 26 (Android 8.0) minimum, API 34 target
- **Disk Space**: ~2GB for dependencies
