# 🚀 Quick Start: Get Authentication Working in 10 Minutes

## TL;DR
1. Create Firebase project
2. Download `google-services.json`
3. Enable Email/Password auth
4. Create Firestore database
5. Build and test!

---

## Step-by-Step (10 Minutes)

### 1️⃣ Create Firebase Project (2 min)
1. Go to https://console.firebase.google.com/
2. Click **"Add project"**
3. Name: `Offline Assessment`
4. **Disable** Google Analytics
5. Click **"Create project"**

### 2️⃣ Add Android App (2 min)
1. Click the **Android icon** (🤖)
2. Package name: `com.examscanner.premium` ⚠️ **MUST MATCH EXACTLY**
3. App nickname: `Offline Assessment`
4. Click **"Register app"**

### 3️⃣ Download Config File (1 min)
1. Click **"Download google-services.json"**
2. Replace the file at:
   ```
   /Users/jcolasi/Desktop/test-scanner/app/google-services.json
   ```
3. Click **"Next"** → **"Next"** → **"Continue to console"**

### 4️⃣ Enable Authentication (2 min)
1. In Firebase Console, click **"Authentication"**
2. Click **"Get started"**
3. Click **"Sign-in method"** tab
4. Click **"Email/Password"**
5. Toggle **Enable** to ON
6. Click **"Save"**

### 5️⃣ Create Firestore Database (2 min)
1. In Firebase Console, click **"Firestore Database"**
2. Click **"Create database"**
3. Choose **"Start in production mode"**
4. Location: **asia-southeast1 (Singapore)**
5. Click **"Enable"**

### 6️⃣ Add Security Rules (1 min)
1. Click **"Rules"** tab in Firestore
2. Paste this:
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```
3. Click **"Publish"**

## Common Issues

### ❌ "google-services.json is missing"
**Fix**: Make sure you replaced the placeholder file with the real one from Firebase

### ❌ "An internal error has occurred"
**Fix**: Enable Email/Password authentication in Firebase Console

### ❌ Build fails with Firebase errors
**Fix**: 
```bash
./gradlew clean
rm -rf app/build
./gradlew assembleDebug
```
