# 📚 Sections Feature Guide

## What are Sections?

**Sections** represent class groups within a subject folder. Think of them as your actual class sections.

### Example Structure:
```
📁 Mathematics (Subject Folder)
   ├─ 📋 Grade 7-A (Section) - 35 students
   ├─ 📋 Grade 7-B (Section) - 38 students
   └─ 📋 Grade 7-C (Section) - 32 students

📁 Science (Subject Folder)
   ├─ 📋 Grade 8-Diamond (Section) - 40 students
   ├─ 📋 Grade 8-Emerald (Section) - 42 students
   └─ 📋 Grade 8-Sapphire (Section) - 38 students
```

## How to Add Sections

### Option 1: From Subject Folder Screen
1. Open a subject folder (tap on folder card)
2. You'll see a "Sections" tab
3. Tap "NEW SECTION" button
4. Enter:
   - Section name (e.g., "Grade 7-A", "Diamond Section")
   - Expected students (capacity)
5. Tap "CREATE"

### Option 2: From Exam Creation
1. When creating an exam
2. Select which section will take the exam
3. This helps organize results by section

## Benefits of Using Sections

### 1. **Organize Students**
- Group students by class section

### 3. **Track Progress**
- See which sections need more help
- Monitor improvement over time

### 4. **Simplify Exam Management**

## Best Practices

### 1. **Naming Conventions**
Good names:
- ✅ Grade 7-A, Grade 7-B
- ✅ Diamond, Emerald, Sapphire
- ✅ Morning Section, Afternoon Section
- ✅ Advanced, Regular

Avoid:
- ❌ Section 1, Section 2 (not descriptive)
- ❌ Very long names
- ❌ Special characters

### 2. **Organization**
- Create sections before creating exams
- One subject can have multiple sections
- Sections help when you have 50+ students

### 3. **Student Assignment**
- Students can be in one section per subject
- Same student can be in different sections for different subjects
- Example: John is in "Grade 7-A" for Math, but "Grade 7-Diamond" for Science

## FAQ

### Q: Do I need to create sections?
**A**: No, sections are optional. If you only have one class, you can skip this feature.

### Q: Can I have the same exam for multiple sections?
**A**: Yes! Create the exam once, then scan students from different sections. You can filter results by section.

### Q: What happens if I delete a section?
**A**: The section is deleted but students and exam results are kept. You can reassign them to another section if needed.

### Q: Can I rename a section?
**A**: Yes, just edit the section name. All linked exams and students will automatically update.

### Q: How many sections can I create?
**A**: Unlimited! Create as many as you need.

### Q: Can sections have different settings?
**A**: In future versions, yes. For now, settings are per-exam, not per-section.
