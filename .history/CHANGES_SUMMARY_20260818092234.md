### 3. Downloadable Answer Sheet Templates: Added ✅

**NEW FEATURE!**

**What It Does:**
- Downloads printable answer sheet templates
- 5 templates: 25, 50, 60, 100, 120 items
- Saves to Downloads folder
- Opens automatically in PDF viewer
- Print-ready format

**How to Use:**
1. Open app → Home screen
2. Tap menu (⋮) in top-right corner
3. Select "Download Templates"
4. Choose a template (e.g., "50 Items")
5. Template downloads → Opens automatically
6. Print the template
7. Use with camera scanner!

**Template Format:**
```
OFFLINE ASSESSMENT - ANSWER SHEET
Template: 50 Items

STUDENT INFORMATION:
Name: ___________________________________
ID: _____________________________________
Date: ___________________________________

INSTRUCTIONS:
• Fill bubbles completely with a pen
• Use the camera scanner to grade automatically
• One answer per question

  1. [ A ] [ B ] [ C ] [ D ]
  2. [ A ] [ B ] [ C ] [ D ]
  ...
 50. [ A ] [ B ] [ C ] [ D ]
```

**Code Changes:**
- `SubjectFolderListScreen.kt`: 
  - Added "Download Templates" menu item
  - Added `TemplateDownloadDialog` composable
  - Added `TemplateDownloadItem` composable
  - Added `generateAnswerSheetPDF()` function
  - Added `downloadTemplate()` function
- `file_paths.xml`: Added downloads directory path

**Files Created:**
- Templates download to: `Downloads/answer_sheet_[XX].pdf`
- Format: Plain text with bubble grid layout
