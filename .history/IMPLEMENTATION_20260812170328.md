### 🚀 How Everything Works

1. **Creating an Exam:**
   - Tap "NEW EXAM" → Enter name & questions → Save
   - Automatically navigates to Edit Key screen
   - Set answer key → Returns to exam list

2. **Scanning Sheets:**
   - Open exam → Tap "SCAN SHEETS"
   - Camera opens → Capture photo
   - ML Kit processes image
   - Extracts student info & answers
   - Saves to database → Shows in scores list

3. **Scoring Flow:**
   - Student answers matched against answer key
   - Score calculated automatically
   - Percentage computed
   - Average updated for class
   - Rankings sorted by performance

4. **Data Flow:**
   - UI → ViewModel → Repository → Database
   - Database emits Flow → ViewModel collects → UI updates reactively
   - All changes sync automatically
