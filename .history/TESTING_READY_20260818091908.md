#### How Templates Work:
1. Tap menu (⋮) in top-right
2. Select "Download Templates"
3. Choose a template (25, 50, 60, 100, or 120 items)
4. Template downloads to Downloads folder
5. PDF opens automatically
6. Print and use with camera scanner!

#### Template Format:
```
OFFLINE ASSESSMENT - ANSWER SHEET
Template: 50 Items
==================================================

STUDENT INFORMATION:
Name: _____________________________________
ID: _______________________________________
Date: _____________________________________

==================================================
INSTRUCTIONS:
• Fill bubbles completely with a pen
• Use the camera scanner to grade automatically
• One answer per question

==================================================

  1. [ A ] [ B ] [ C ] [ D ]    26. [ A ] [ B ] [ C ] [ D ]
  2. [ A ] [ B ] [ C ] [ D ]    27. [ A ] [ B ] [ C ] [ D ]
  ...
 25. [ A ] [ B ] [ C ] [ D ]    50. [ A ] [ B ] [ C ] [ D ]

==================================================
```
