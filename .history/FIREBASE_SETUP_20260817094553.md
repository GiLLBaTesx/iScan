# 🔥 Firebase Setup Instructions

## Prerequisites
- Google Account (free)
- This project already has Firebase dependencies added

---

## Step 1: Create Firebase Project

1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Click **"Add project"** or **"Create a project"**
3. Enter project name: **"Offline Assessment"** (or any name you prefer)
4. Disable Google Analytics (optional, saves setup steps)
5. Click **"Create project"**
6. Wait for project creation (takes ~30 seconds)

---

## Step 2: Add Android App to Firebase

1. In Firebase Console, click the **Android icon** (🤖) or "Add app"
2. Fill in the form:
   - **Android package name**: `com.examscanner.premium` (MUST match exactly!)
   - **App nickname**: Offline Assessment (optional)
   - **Debug signing certificate SHA-1**: Leave blank for now
3. Click **"Register app"**

---

## Step 3: Download google-services.json

1. Firebase will show a **"Download google-services.json"** button
2. Click it to download the file
3. **Replace** the existing `app/google-services.json` file in your project with this downloaded file
   - Location: `/Users/jcolasi/Desktop/test-scanner/app/google-services.json`
   - The current file is just a placeholder
4. Click **"Next"** and **"Next"** again (dependencies already added)
5. Click **"Continue to console"**

---

## Step 4: Enable Authentication

1. In Firebase Console, click **"Authentication"** in the left sidebar
2. Click **"Get started"**
3. Click on **"Sign-in method"** tab
4. Enable **"Email/Password"**:
   - Click on "Email/Password"
   - Toggle **Enable** to ON
   - Leave "Email link (passwordless sign-in)" disabled
   - Click **"Save"**

---

## Step 5: Set Up Firestore Database

1. In Firebase Console, click **"Firestore Database"** in the left sidebar
2. Click **"Create database"**
3. Choose **"Start in production mode"** (we'll add rules next)
4. Select location: **asia-southeast1 (Singapore)** (closest to Philippines)
5. Click **"Enable"**
6. Wait for database creation (~30 seconds)

---

## Step 6: Configure Firestore Security Rules

1. In Firestore Database, click the **"Rules"** tab
2. Replace the existing rules with:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // Users can only access their own data
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
    
    // Built-in templates are read-only for authenticated users
    match /templates/{templateId} {
      allow read: if request.auth != null;
      allow write: if false;
    }
    
    // MELCs are read-only for authenticated users
    match /melcs/{melcId} {
      allow read: if request.auth != null;
      allow write: if false;
    }
  }
}
```

3. Click **"Publish"**

## Troubleshooting

### Build Error: "google-services.json is missing"
- Make sure you downloaded the real `google-services.json` from Firebase
- Place it in `app/google-services.json` (not the root folder!)

### Build Error: "google-services plugin could not detect"
- Verify package name in `google-services.json` matches: `com.examscanner.premium`
- Clean and rebuild: `./gradlew clean build`

### Auth Error: "An internal error has occurred"
- Make sure Email/Password authentication is enabled in Firebase Console
- Check internet connection
- Wait a few minutes for Firebase changes to propagate

### Firestore Error: "Missing or insufficient permissions"
- Verify Firestore security rules are published
- Check that user is authenticated before accessing Firestore
- Verify user ID in Firestore matches Firebase Auth UID
